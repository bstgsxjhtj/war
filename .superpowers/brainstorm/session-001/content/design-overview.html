设计方案：骨骼动画 + 地图扩展

两种核心进化的技术方案与视觉概览

🦴 方案A：骨骼动画系统

推荐方案：程序化骨骼系统（无需外部资源）

在现有 CapsuleGeometry 身体上建立 Three.js Bone 层级，程序化生成关键帧动画。攻击/格挡/闪避/死亡全动画化，不依赖 Mixamo 或 GLTF 文件加载，保持 Demo 零外部资源特性。

14块骨骼：head → neck → chest → hips 为主干，肩/肘/腕×2 为手臂，大腿/膝/脚×2 为腿部。现有 CapsuleGeometry 部件绑定到对应骨骼，通过旋转骨骼驱动动画。

动画状态机：idle(呼吸) / walk / run / attack1-3(三连击) / block / dodge / charge / hurt / death / execute。每个状态定义关键骨骼在 t=0/0.3/0.6/1.0 的旋转角度，用 lerp 插值。

🗺️ 方案B：多地图系统

推荐方案：MapGenerator 多布局系统

新建 MapGenerator 类，生成4种地形布局。每种地图定义地形尺寸/高度函数/物体分布/刷新点。M键切换模式时自动加载对应地图，或在大厅选图。

🌉 渡桥战

大河横贯地图，仅一座窄桥通行。弓兵两岸对射，步兵桥头争夺。咽喉战略。

⛰️ 山口战

两侧山崖形成狭长谷道。高地弓兵压制，步兵谷底推进。高低差战斗。

🏰 攻城战

蓝方攻城门，红方守城墙垛口。城内多房间CQB。非对称攻防。

🌾 遭遇战

开阔平原散布岩石树木掩体。双方远距遭遇，利用地形掩护推进。开放机动。

地形高度：使用噪声+正弦函数生成起伏，渡桥有河流低洼、山口有两侧高地、攻城有城墙高耸、遭遇有缓坡。

物体分布：每种地图定义树木/岩石/建筑/旗帜/补给点/刷新点的布局参数，Environment 按布局生成。
