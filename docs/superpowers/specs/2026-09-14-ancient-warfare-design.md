# 古代冷兵器对战 3D 游戏 — 设计文档

## 1. 概述

一款第三人称（TPS）古代冷兵器对战游戏，玩法形态类似 CS 的局制遭遇战，但用刀、弓、枪、剑等冷兵器替代枪械。一期交付一个可在浏览器运行的最小可玩 Demo，架构预留多人 + AI、攻城、河流等扩展。

## 2. 需求摘要

| 维度 | 决策 |
|------|------|
| 平台 | Web（Three.js + Vite） |
| 模式 | 单机 vs AI（架构预留多人扩展） |
| 视角 | 第三人称 TPS |
| 致死模型 | 血条 + 武器差异化伤害 |
| 画面 | 低面模型 + 后期特效（泛光/雾/色调映射） |
| 一期范围 | 最小可玩闭环：1 场景 + 2 武器(刀/弓) + 3-5 AI |
| 扩展点 | 多人同步、攻城、河流、4 武器、兵种 |

## 3. 玩法设计

### 3.1 对局
- 两阵营遭遇战：玩家所在蓝方 vs AI 红方，每方 1-5 人。
- 胜负：歼灭对方阵营；单局制，可重开。

### 3.2 武器（一期 2 种，结构支持 4 种）
| 武器 | 类型 | 距离 | 攻速 | 伤害 | 弹道 |
|------|------|------|------|------|------|
| 刀 | 近战 | 短 | 高 | 中 | 即时命中(扇形) |
| 弓 | 远程 | 远 | 低 | 中高 | 抛物线/直射弹丸 |
| 长枪(扩展) | 中距离 | 中 | 中 | 高 | 即时命中(锥形刺) |
| 剑(扩展) | 中距离 | 中 | 中 | 中高 | 即时命中(扇形) |

### 3.3 操作
- WASD 移动；鼠标控制视角/朝向；左键攻击；右键格挡(近战)/瞄准拉弓(弓)；
- Shift 冲刺；空格跳跃；1/2 切换武器。

### 3.4 战斗循环
输入 → 角色状态机(移动/攻击/受击/死亡) → 武器攻击判定 → 血量更新 → 死亡/重生 → 计分 → 局结束。

## 4. 架构设计

### 4.1 分层
```
core/      引擎无关：ECS、EventBus、GameState、Time
engine/    Three.js 渲染层：Renderer、Scene、Camera、AssetLoader
gameplay/  游戏逻辑：Player、AIController、Weapon、Health、CombatSystem
world/     Terrain、Environment
ui/        HUD
net/       Transport（多人扩展预留抽象接口）
main.js    入口与游戏主循环
```

### 4.2 核心抽象
- **ECS**：实体=ID，组件=数据，系统=逻辑；战斗实体（角色/弹丸）统一走 ECS。
- **GameState**：有限状态机管理 局/回合/暂停/结束。
- **EventBus**：解耦模块（命中、死亡、得分通过事件传播）。
- **AIController**：状态机（巡逻/追击/攻击/撤退），可替换为玩家输入或网络输入。
- **net/Transport**：定义输入同步抽象，单机用本地输入，多人替换为 WebSocket，核心战斗逻辑不变。

### 4.3 数据流
输入层(本地/AI/网络) → Intent → 角色状态机 → ECS 变更 → 渲染层同步 → 事件总线广播 → HUD/计分。

### 4.4 多人扩展点
- 所有实体操作走 Intent 命令，本地与远端只差输入来源。
- Transport 接口：sendIntent / onRemoteState，一期空实现。

## 5. 素材方案（低面 + 后期，无需用户绘画）

| 资产 | 方案 | 兜底 |
|------|------|------|
| 角色 | 低面人形（程序化几何拼装） | 免费 glTF |
| 武器 | Box/Torus 几何体拼装 | — |
| 地形 | PlaneGeometry + 噪声高度图 | — |
| 植被/旗帜 | 程序化低面 | — |
| 贴图 | 程序化 Canvas 贴图 | CC0 纹理 |
| 动画 | 自建插值动画（挥砍/拉弓） | Mixamo |
| 后期 | UnrealBloomPass + 雾 + ACES 色调映射 | — |

## 6. 错误处理
- 资产加载失败：占位几何体兜底 + 控制台告警。
- 物理穿透：攻击判定用距离/角度保守判定，不依赖高精度物理。
- 帧率：固定时间步长更新逻辑，渲染插值。

## 7. 测试
- 单元：ECS 增删查、武器伤害表、状态机迁移（Vitest）。
- 手动验证：npm run dev 后场景渲染、移动、攻击命中、AI 反应。

## 8. 一期验收标准
- 浏览器打开可见有氛围的古代战场场景。
- TPS 相机跟随，WASD + 鼠标可移动角色。
- 刀左键可对 AI 造成伤害并扣血；弓可射弹丸命中。
- AI 能追击并攻击玩家。
- HUD 显示血条/计分。
- 全军覆没一方判负，可重开。
